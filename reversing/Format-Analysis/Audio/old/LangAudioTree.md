
`\GAMEFILES\USRDIR\ASSETS_1_AUDIO_STREAMS\EN`

KEY

File:
d_<char><set?>_<ctx>_<id>.exa.snu

d_ = dialogue

<char> = short character code, e.g. as (alien), fr (French guy), lg (logger), moe/moer (Moe), uter (Üter), teen (Squeaky-Voiced Teen), etc.

<set?> = sometimes a two-digit set number tied to the numbered bank (e.g. as01, fr02, lg02).

<ctx> = a tiny context chunk; you often see xxx for “generic”, but there are others in your list (igc for cutscenes, level tags like gr/bsh/nvq, etc.).

<id> = the 7-digit line index.


snu format known by vgmstream
